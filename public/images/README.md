# 画像ファイル一覧

各事例フォルダに以下のファイル名で画像を配置してください。
推奨形式: JPG

---

## case1/ (28歳 女性) - 画像3枚
- `before1.jpg` - 施術前写真
- `front_2025-06-01.jpg` - 正面 2025/06/01
- `front_2025-07-01.jpg` - 正面 2025/07/01

---

## case2/ (35歳 男性) - 画像2枚
- `before1.jpg` - 施術前写真
- `before2.jpg` - 施術後写真

---

## ファイル名の規則
- `before1.jpg` - 施術前写真
- `before2.jpg` - 施術後写真（case2）
- `front_YYYY-MM-DD.jpg` - 正面の写真（日付付き）
